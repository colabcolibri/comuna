# UX research checklist

Use before marking `/ux-pass` complete.

## Personas (`03_user_types`)

- [ ] Each persona has goal, context, pain, and success signal
- [ ] Out-of-scope users named explicitly
- [ ] No invented demographics without `Assumption:` label
- [ ] Accessibility and literacy constraints noted when relevant

## Research quality

- [ ] Claims tied to brief, inventory, or cited user input — not generic UX blog filler
- [ ] Jobs-to-be-done stated as outcomes, not feature lists
- [ ] Open questions listed for `product-owner` or human validation

## Handoff to design

- [ ] Journey hypotheses documented (routes/screens) for `design-system-owner` `/design-flow`
- [ ] No hex codes or component names — that is `09` / Harmonia

## Privacy

- [ ] PII handling flagged → `security-champion` if regulated data
