# GEO checklist — `/seo-pass geo`

> Generative Engine Optimization — help AI systems **accurately cite** your public product content. Stack-agnostic.

## Prerequisites

- [ ] `/seo-pass bootstrap` or existing `12_marketing_seo.md`
- [ ] Public pages that should be cited (docs, marketing, changelog, API reference)

## Full geo pass

- [ ] Clear entity: product name, category, primary URL in `12`
- [ ] Factual, stable “about” content (avoid vague marketing-only copy on key pages)
- [ ] Structured data (schema.org) aligned with real page content — no false claims
- [ ] FAQ or explainer pages for top user questions (citation-friendly headings)
- [ ] Technical docs: code examples that match current API (`07` consistency)
- [ ] Changelog / release notes public when cited version matters
- [ ] robots allows indexation of cite-worthy paths (not blocking docs mistakenly)
- [ ] llms.txt or equivalent discovery file documented if used — optional pattern
- [ ] E-E-A-T signals: authorship, update dates, contact — per public site policy

## Out of scope

- Manipulating AI rankings or hidden prompt injection
- Paying for AI placement
- Private or authenticated content GEO (different threat model — see `02`)
